# Stable Cellulase Generator

A two-phase machine-learning pipeline for generating novel fungal cellulase sequences using a Conditional Variational Autoencoder (CVAE) and a CNN stability predictor.

The pipeline was developed and executed in two sequential phases. Phase 1 was an exploratory screen using a pilot corpus that produced experimentally tested candidates. Phase 2 used those experimental results to anchor a larger, retrained model in latent space, producing a focused set of predicted-stable variants for synthesis.

> **Data** [[DOI]](https://doi.org/10.5281/zenodo.20594473)  
> Training corpora and generated candidate files are deposited at the Zenodo record above. Download them before running either script.

---

## Scientific background and rationale

Designing cellulases with improved stability under industrial process conditions is challenging because most natural fungal cellulases were not evolved for the elevated temperatures, non-physiological pH, and prolonged residence times typical of lignocellulose-to-bioethanol workflows. Generative models offer a way to explore the sequence space around known functional enzymes without exhaustive mutagenesis, but unconditioned sampling from a learned prior tends to produce sequences with no particular relationship to any experimentally validated starting point.

The two-phase design adopted here addresses this directly. Phase 1 used the generative model to produce a broad initial set of candidate sequences without any experimental bias. Those candidates were tested in a 3,5-dinitrosalicylic acid (DNS) reducing-sugar assay against a commercial positive control. Two sequences — designated PF2 and PF3 — showed cellulolytic activity exceeding the commercial control (108 % and 124 % of PC activity respectively; Welch t-test, PF3 p = 0.0003, PF2 p = 0.067). These two sequences became the anchors for Phase 2, in which a larger, retrained model was used to generate new sequences by sampling the latent neighbourhood around those validated starting points rather than from the uninformed prior.

## Phase 1 — Exploratory generation

**Script:** `cellulase_generator.py`  
**Training corpus:** `cellulase_positive_Phase1.csv` (Zenodo, ~1,212 sequences)  
**Models saved:** no — Phase 1 model artefacts are not available

Phase 1 used a pilot corpus of approximately 1,212 curated fungal cellulase sequences. A CVAE and a CNN stability predictor were trained on this corpus and used to generate a set of candidate sequences. No model checkpoints were saved at the conclusion of Phase 1 because the purpose of the phase was candidate discovery rather than downstream reuse.

A panel of Phase 1 candidates (PB1, PB2, PF1, PF2, PF3, PF4) was expressed and assayed for cellulolytic activity using the DNS reducing-sugar assay against a 1 % (w/v) carboxymethylcellulose substrate. PF2 and PF3 were the only candidates to exceed the activity of the commercial positive control and were selected as the anchor sequences for Phase 2. This selection was based on experimental activity measurement, not on computational scoring, giving Phase 2 a biologically grounded starting point.

---

## Phase 2 — Anchor-guided generation

**Script:** `phase2.py`  
**Training corpus:** `cellulase_positive_Phase1.csv` (Zenodo, ~3,845 sequences after quality filtering)  
**Anchor sequences:** `cellulase_positive_Phase2.xlsx` (Zenodo, PF2 and PF3)  
**Models saved:** yes — artefacts available on Zenodo

Phase 2 retraining used an expanded corpus of approximately 3,845 fungal cellulase sequences, filtered to those with computed Guruprasad instability index between 18.26 and 35 and isoelectric point between 4.05 and 6.00. A new CVAE and CNN stability predictor were trained from scratch on this larger corpus and all four model artefacts were saved.

PF2 and PF3 were then encoded into the 128-dimensional latent space of the retrained CVAE to produce two anchor vectors. New candidate sequences were generated by sampling Gaussian noise around each anchor rather than from the uninformed prior. This biases the generation process towards the latent neighbourhood of enzymes that are known to be active, substantially increasing the probability that generated sequences retain cellulolytic function.

## Usage

### Option A — Use pretrained Phase 2 models (recommended)

Download all Zenodo files, place them in the working directory, and run guided generation directly:

```bash
python phase2.py
```

This skips retraining entirely and uses the saved Phase 2 model artefacts as-is.

### Option B — Retrain from scratch (Phase 2)

Only necessary if you want to reproduce model training or adapt the pipeline to a different corpus. Phase 1 models are not available; this command retrains the Phase 2 models.

```bash
python cellulase_generator.py
```

Expected runtime: approximately 1–3 hours on a modern GPU.  
On completion, `encoder_7k.h5`, `decoder_7k.h5`, `predictor_7k.h5`, and `meta_scaler_7k.pkl` will be written to the working directory.

### Inspect median metadata (optional)

```bash
python statistics.py
```

Prints the median physicochemical metadata values across the training corpus. Phase 2 guided generation conditions the decoder on these medians; this script lets you inspect or override them.

## How Phase 2 guided generation works

1. **Anchor encoding.** PF2 and PF3 are one-hot encoded, their metadata standardised with the persisted scaler, and passed through the encoder to obtain two latent anchor means.

2. **Adaptive sampling radius.** The Euclidean distance *d* between anchor means is computed. The sampling standard deviation is set as σ = clip(0.2 × *d*, 0.1, 0.4). In the published run *d* = 9.7 and σ = 0.4 (the cap binds). The cap prevents sampling from straying outside the region where the decoder has been trained.

3. **Latent sampling.** 1,500 latent vectors are drawn from *N*(μ_anchor, σ²*I*) around each anchor, plus 25 linear interpolations between the two anchor means.

4. **Decoding and filtering.** Each latent vector is decoded to a candidate sequence. The stability predictor is applied; candidates with predicted instability index ≥ 40 are discarded.

5. **Composite scoring.** Each surviving candidate is re-encoded to obtain its posterior mean. A composite score is computed as 0.7 × (1 − normalised instability) + 0.3 × (1 − normalised latent distance to nearest anchor).

6. **Diversity selection.** Mini-batch K-means (k = 10–12) is applied in latent space. The top-scoring candidate per cluster is selected.

7. **Output.** The top 10 candidates per anchor are written to CSV and FASTA files.

## Reproducibility

A single random seed (42) is propagated to NumPy, TensorFlow, and `train_test_split` at the top of each script. Running Phase 2 training on the same hardware and software stack with the deposited data should reproduce model weights equivalent to the artefacts on Zenodo.

Note that Phase 1 model artefacts are not available because they were not saved at the time of the original run. If you need to inspect Phase 1 generation, run `cellulase_generator.py` with `cellulase_positive_Phase1.csv` after adjusting the expected row count to the Phase 1 corpus size (~1,212 sequences). The Phase 1 corpus is not separately deposited; contact the authors if it is required.
